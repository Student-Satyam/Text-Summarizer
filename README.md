# Simple Text Summarizer with Streamlit

## Description
This project provides a simple web application using Streamlit to summarize text. It leverages OpenAI's `gpt-4o-mini` model to generate concise summaries from user-provided text.

## Features
- Intuitive web interface for text input.
- Real-time summarization using OpenAI's powerful language model.
- Easy to set up and deploy.
